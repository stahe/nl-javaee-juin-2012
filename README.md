# Inleiding tot Java EE 5 / 6

👉 Online cursus:
[https://stahe.github.io/nl-javaee-juin-2012/](https://stahe.github.io/nl-javaee-juin-2012/)

## Overzicht

Dit werkboek (juni 2012) biedt een praktische inleiding tot **Java EE** aan de hand van de ontwikkeling van een **drielaagse** applicatie:

* Overzicht
* Bedrijfslogica
* Toegang tot gegevens

Het document is gebaseerd op Java EE 5 en 6 en maakt gebruik van **Maven-projecten**.

## Behandelde technologieën

### Webapplicatie

* JSF (Java Server Faces)
* EJB3 of Spring (bedrijfslogica)
* JPA (Hibernate / EclipseLink)

### Client/server-applicatie

* Swing (grafische client, Spring-ondersteuning)
* EJB3 of webservices (server)

## Leerdoelen

* De architectuur van een Java-bedrijfsapplicatie begrijpen
* EJB3 en Spring vergelijken
* JPA implementeren voor persistentie
* Een complete applicatie bouwen met NetBeans

Het document biedt de basisstructuren van de oplossingen en laat het aan de student over om bepaalde delen in te vullen.

## Vereisten

* Kennis van de programmeertaal Java
* NetBeans IDE (ongeveer 1 GB RAM aanbevolen)
